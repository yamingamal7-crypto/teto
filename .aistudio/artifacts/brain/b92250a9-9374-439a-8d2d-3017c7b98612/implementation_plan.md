# خطة تنفيذ مكتملة: نظام كاشير وإدارة TITO STORE (POWERED BY ZEUS)

تم ترقية وتطوير النظام بالكامل ليعمل كـ **نظام كاشير ونقاط بيع متكامل (Full-fledged Cashier & POS Workstation)** مطابق للهوية البصرية الرسمية لمتجر **TITO STORE (POWERED BY ZEUS)**:

---

## المكونات المضافة والمطورة:

1. **الهوية البصرية الرسمية (TITO STORE Identity):**
   - اعتماد الألوان الرسمية: الأسود الكربوني الداكن `#0a0a0a`، الأحمر الناري للسباقات `#dc2626` / `#e11d48`، الأبيض الصريح `#ffffff`، والرمادي التيتانيوم `#18181b`.
   - إبراز شعار `TI` (بالأحمر) و `TO` (بالأبيض) مع وسم `— STORE —` وتوقيع `POWERED BY ZEUS`.
   - حصر الماركات رسمياً: **شيفروليه | أوبل | MG | إسبيرانزا** وشعاراتها المعتمدة.

2. **محطة الكاشير وفواتير البيع (CashierTerminal.tsx):**
   - **واجهة فواتير متعددة البنود:** إضافة الأصناف بنقرة واحدة أو بمسح الباركود السريع.
   - **قارئ الباركود وأكواد T2-PH:** إدخال كود الصنف أو الباركود وإضافته مع تنبيهات فورية لحالة المخزون.
   - **بيانات العميل والسيارة:** تسجيل اسم العميل، رقم الهاتف، ونوع السيارة ورقم اللوحة.
   - **حاسبة المدفوعات والخصومات:** خصم فوري بنسبة مئوية (5%، 10%)، واختيار وسيلة الدفع (نقدي، إنستاباي، فيزا، آجل).
   - **حساب الفكة والمتبقي:** إدخال المبلغ المستلم وحساب المتبقي تلقائياً.
   - **طباعة الإيصال الحراري (Thermal Receipt 80mm):** نافذة منبثقة تحاكي ورق طابعات الكاشير الحرارية بشعار المتجر وتفاصيل الفاتورة مع زر طباعة مباشر.
   - **الخصم التلقائي للرصيد:** بمجرد إتمام الفاتورة يتم خصم الكميات لحظياً من شيت المخزون.

3. **تقرير المبيعات اليومي والرسوم البيانية (DailySalesReport.tsx عبر Recharts):**
   - **مخطط المبيعات الساعي (AreaChart):** منحنى حركة الإيراد وعدد الفواتير على مدار ساعات العمل من 9:00 ص إلى 10:00 م.
   - **مخطط القطع الأكثر مبيعاً (BarChart أفقي):** ترتيب القطع الأكثر طلباً (تيل فرامل، مواسير مياه GM، سيور كاتينة Gates، بدال بنزين، كولر زيت).
   - **توزيع المبيعات حسب ماركة السيارة (Donut PieChart):** نسب مبيعات شيفروليه، أوبل، MG، وإسبيرانزا بالألوان المعتمدة وعرض اللوجوهات.
   - **شريط مؤشرات الأداء اليومية (KPIs):** إجمالي الإيراد، عدد الفواتير، صافي الأرباح، متوسط الفاتورة، وعدد القطع المباعة.
   - **جدول الفواتير التفصيلي:** قائمة بجميع الحركات المنفذة اليوم مع وسيلة الدفع واسم الكاشير.

4. **جاهزية النظام والتوافق:**
   - البناء والتجميع (`compile_applet`) ناجح 100%.
   - الفحص البرمجي (`lint_applet`) خالٍ تماماً من أي أخطاء أو تعارضات.
